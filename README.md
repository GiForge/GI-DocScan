# 📄 Smart Document Scanner

Uno scanner documentale professionale per Android progettato per acquisire, correggere, ottimizzare e riconoscere documenti direttamente sul dispositivo, senza dipendere da servizi cloud esterni.

✅ 100% On-Device  
✅ OCR Offline  
✅ Correzione Prospettica Avanzata  
✅ Esportazione PDF Multipagina  
✅ Text-to-Speech Integrato  
✅ Nessun caricamento dei dati su server remoti
